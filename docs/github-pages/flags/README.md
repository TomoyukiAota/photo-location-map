# Flags

The flag beside each language of the website's language picker
(`../i18n.js`), one file per language.

They are the files of the [flag-icons](https://github.com/lipis/flag-icons)
package, 7.6.0, in their rectangular shape (`flags/4x3/`), copied as they are.
Its license is `LICENSE`, here. The application has the same flags, from the
same package (`src-shared/i18n/languages.ts`).
